# 從終端機指令擷取第一個參數作為 Topic 名稱
topic = sys.argv[1]

# 用該 Topic 實例化並啟動監聽節點
profiler = PCProfiler(topic)

### 2. 精準萃取與過濾雜訊 (Data Parsing & Filtering)

原始的 `PointCloud2` 是複雜的二進位資料。這裡使用了 ROS 內建的 `pc2.read_points` 工具，並且**只萃取空間座標 (x, y, z)**，同時開啟了 `skip_nans=True`，自動把感測器打向天空或無效反射所產生的 `NaN` (空值) 丟棄。

Python

```python
# 提取 x, y, z 座標，過濾無效點，並直接轉成高效的 numpy 陣列
points = np.array(
    list(pc2.read_points(msg, field_names=("x", "y", "z"), skip_nans=True)),
    dtype=np.float32,
)
```

### 3. 防呆安全機制 (Safety Guard)

在進行任何數學運算前，先檢查過濾完的點雲是不是空的。如果感測器異常或全被遮擋導致點數為 0，程式會印出警告並直接跳過這一幀，避免後續取最大/最小值時造成程式崩潰 (Crash)。

Python

```python
n_points = len(points)
if n_points == 0:
    rospy.logwarn("[%s] Received empty point cloud", self.topic)
    return # 提早結束，保護程式
```

### 4. 高效的邊界運算 (Bounding Box Calculation)

利用 `numpy` 矩陣運算的強大效能，透過設定 `axis=0` (沿著直行運算)，一行程式碼就能瞬間從幾萬個點當中，分別找出 X、Y、Z 軸的最小與最大值。這能幫你快速確認感測器的偵測範圍有沒有偏移。

Python

```python
# 沿著列 (axis=0) 比較，直接找出 3 個軸的最小值與最大值
x_min, y_min, z_min = points.min(axis=0)
x_max, y_max, z_max = points.max(axis=0)
```

### 1. 動態獲取自駕車速度

程式會持續監聽底盤回傳的車速向量，並利用畢氏定理算出車輛真實的行進速率，存入 `self.ego_speed` 供後續補償使用。

Python

```python
def ego_speed_callback(self, msg):
    # 將 x 與 y 方向的向量合成為實際的絕對速度 (m/s)
    self.ego_speed = math.hypot(msg.vector.x, msg.vector.y)
```

### 2. 核心運算：過濾靜止背景 (Ego-Motion Compensation)

這是整支程式的靈魂。如果路邊有一棵樹，雷達測到的「相對速度」會剛好是負的「自車速度」。我們將兩者相加得到「絕對速度」，只要數值小於容錯值（0.8 m/s），就判定為靜止物體並剃除。

Python

```python
# 1. 物理公式：物件絕對速度 = 雷達相對速度 + 自車速度
v_abs = vrel + self.ego_speed

# 2. 建立遮罩：只保留絕對速度 > 0.8 m/s 的真正動態障礙物
dynamic_mask = np.abs(v_abs) > STATIONARY_TOLERANCE

# 3. 套用遮罩，把靜止背景的座標與速度全數濾除
x = x[dynamic_mask]
vrel = vrel[dynamic_mask]
```

### 3. 精準綁定標籤 (消除殘影)

為了避免 RViz 上的速度標籤亂跳或產生殘影，而是直接提取雷達硬體已經追蹤好的 `ID` 欄位，將它設定為 Marker 的專屬身分證。

Python

```python
# 從雷達資料中提取硬體追蹤 ID
obj_id = int(current_ids[i])

# 將 RViz 標籤的 ID 綁定為該車輛的 ID，確保標籤穩穩吸附
marker.id = obj_id
current_frame_ids.add(obj_id) # 紀錄目前畫面上還存活的車輛
```

### 4. 回收機制

如果一台車轉彎離開了雷達視野，它的 ID 就會消失。程式會比對「上一幀」與「這一幀」的 ID 差異，針對消失的物件發送 `DELETE` 指令給 RViz。

Python

```python
# 找出「上一幀有」但「這一幀不見」的車輛 ID
missing_ids = self.active_object_ids - current_frame_ids

for missing_id in missing_ids:
    del_marker = Marker()
    del_marker.id = missing_id
    del_marker.action = Marker.DELETE # 告訴 RViz 把這個標籤刪掉
    marker_array.markers.append(del_marker)
```

這樣的寫法既保證了**數學邏輯的正確性**（不怕跟車時前車消失），又兼顧了 **ROS 視覺化的穩定性**（無殘影、無閃爍）。

# 光達測距技術：相位偏移法 (Phase-Shift)

相位偏移法（Phase-Shift）與常見的飛行時間法（ToF）不同，它通常不發射短促的脈衝，而是發射**連續波 (Continuous Wave, CW)** 雷射，並對其進行振幅調變 (Amplitude Modulation)。這種技術特別適合對精度要求極高的中短距離測量。

## 詳細原理

1. **發射連續波**：光達系統發射一個帶有特定調變頻率 ($f$) 的連續光波訊號。

2. **接收與比對**：當光波擊中目標物體並反射回到接收器時，接收到的波形會與系統原始發射的波形產生一個**相位延遲**（也就是相位差，$\Delta \phi$）。

3. **推算距離**：因為光速與調變頻率是已知的，系統只要計算出這兩個波的相位差，就能精確推算光波在空中往返的總距離。

## 距離計算公式

距離 ($d$) 的推導公式如下：


$$d = \frac{c}{2f} \cdot \frac{\Delta \phi}{2\pi}$$


* **$d$**：目標物體的距離
* **$c$**：光速（約 $3 \times 10^8$ m/s）
* **$f$**：雷射的振幅調變頻率
* **$\Delta \phi$**：測量到的相位延遲（以弧度表示）
