#### 1. Briefly explain your code

本程式碼實作了一個卡爾曼濾波器 (Kalman Filter) 來追蹤二維平面上的移動軌跡，主要分為兩個檔案：

- **`filtered_path.py`**：負責模擬環境與資料生成。
    
    - `virtual_path` 類別會產生三種軌跡：無雜訊的理想軌跡 (`ideal_path`)、加入控制雜訊的真實軌跡 (`real_path`)，以及加入感測雜訊的觀測軌跡 (`measurement`)。
        
    - 主程式建立卡爾曼濾波器物件後，將每個時間點的控制輸入 (`u`) 與含有雜訊的觀測值 (`z`) 丟入濾波器進行預測與更新，並將過濾後的軌跡 (`filtered_path`) 視覺化。
        
- **`kalman_filter.py`**：實作卡爾曼濾波器的核心演算法。
    
    - 定義了狀態矩陣 (包含 x, y 座標與偏航角 yaw)、狀態轉移矩陣 (A)、控制矩陣 (B)、觀測矩陣 (C)。
        
    - 包含 `predict` 方法 (根據物理模型與控制輸入預測下一狀態) 與 `update` 方法 (根據觀測誤差與預測誤差計算卡爾曼增益並修正狀態)。

#### 3. How you design the observation matrix (C)?

系統的狀態向量為一個 $3 \times 1$ 的矩陣：`[x, y, yaw]`。然而，在感測器觀測時，我們只能量測到位置的 `x` 與 `y` 座標，無法直接測量偏航角 (`yaw`)。為了將 $3 \times 1$ 的狀態空間正確映射到 $2 \times 1$ 的觀測空間，觀測矩陣 C 被設計為一個 $2 \times 3$ 的矩陣：

$C = \begin{bmatrix} 1 & 0 & 0 \\ 0 & 1 & 0 \end{bmatrix}$

藉由這樣的設計，當執行 $C \times \text{state}$ 時，就能提取出 `x` 與 `y` 作為預期的觀測值。


#### 4. How you design the covariance matrices (Q, R)?


- **R 矩陣 (狀態轉移誤差共變異數 / Process Noise Covariance)**：這是一個 $3 \times 3$ 的對角矩陣。它用來表示對「系統預測模型」的不確定性程度。由於程式在控制輸入上加入了變異數的雜訊，R 矩陣對應了 x, y 與 yaw 在預測階段的誤差容忍度。
    
- **Q 矩陣 (測量誤差共變異數 / Measurement Noise Covariance)**：這是一個 $2 \times 2$ 的對角矩陣。它代表對「感測器觀測值」的不確定程度。因為我們只觀測 x 和 y，所以它被設計為 $2 \times 2$ 矩陣，其值對應於感測器的雜訊變異數。
    


#### 5. Set the variance in the Q matrix to 0.001 and in the R matrix to 1000. Explain how these settings impact the Kalman filter's performance and output.

![[RQ1000D0.001.png]]
在此設定下，測量雜訊矩陣 (Q) 的值極小，代表我們極度信任感測器的觀測值；狀態轉移雜訊矩陣 (R) 的值極大，代表我們非常不信任預測模型。

這種設定會使得卡爾曼增益 (Kalman Gain) 變大，狀態更新幾乎完全依賴觀測值。如報告中的第二張圖所示，過濾後的軌跡完全擬合觀測數據點，呈現劇烈的鋸齒狀，失去了濾波平滑的作用。

#### 6. Set the variance in the R matrix to 0.001 and in the Q matrix to 1000. Explain how these settings impact the Kalman filter's performance and output.

![[RQ0.001D1000.png]]

在此設定下，狀態轉移雜訊矩陣 (R) 的值極小，代表我們極度信任預測模型；測量雜訊矩陣 (Q) 的值極大，代表我們非常不信任感測器的觀測值。

這種設定會使得卡爾曼增益趨近於零，濾波器會幾乎忽略觀測值，僅依賴物理模型與控制輸入進行推算。如報告中的第三張圖所示，過濾後的軌跡會非常平滑與理想的模型輸出重疊，但由於完全忽略了觀測資料，累積的系統預測誤差無法被修正，導致軌跡逐漸偏離真實軌跡產生漂移。

#### 7. How will the value of Q and R affect the output of Kalman filter?

Q 與 R 的相對大小決定了卡爾曼濾波器在「感測器測量值」與「系統預測模型」之間的權重取捨：

- **信任測量 (Q 小、R 大)**：濾波器會緊跟測量點，反應迅速但容易受到感測器雜訊干擾，導致軌跡劇烈震盪。
    
- **信任模型 (R 小、Q 大)**：濾波器會忽略測量點，軌跡會極度平滑，但無法及時修正累積的過程誤差，容易產生遲滯或軌跡漂移。
    
- 只有適當地調整這兩個矩陣的比例，才能計算出最佳的卡爾曼增益，使濾波器既能平滑雜訊，又能準確追蹤真實的動態軌跡。
